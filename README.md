# مولّدتي — نظام إدارة اشتراكات المولدة

تطبيق ويب كامل: تسجيل دخول، قاعدة بيانات دائمة (SQLite)، مشتركون، اشتراكات شهرية، دفعات، ديون، مصاريف، تقارير، ولوحة تحكم.
**لا يستخدم Local Storage** ولا أي بيانات وهمية، وبدون أي مكتبات خارجية (لا حاجة لـ `npm install`).

## التشغيل

المطلوب: **Node.js 22.13 أو أحدث** (https://nodejs.org)

```bash
cd generator-app
node server.js
```

افتح http://localhost:3000 ثم أنشئ حسابك من «حساب جديد».
تُحفظ كل البيانات في الملف `data/generator.db` وتبقى بعد إغلاق الموقع وإعادة تشغيل الخادم.

## الاختبار

```bash
npm test
```

يشغّل 35 اختباراً: التسجيل والدخول والخروج، حماية الصفحات والـ API، عزل بيانات المستخدمين،
إضافة/تعديل/حذف المشتركين والدفعات والمصاريف، صحة أرقام Dashboard والتقارير، واستعادة كلمة المرور،
وبقاء البيانات بعد إعادة تشغيل الخادم.

## طريقة حساب الأرقام

| الرقم | التعريف |
|---|---|
| الإيرادات | مجموع الاشتراكات الشهرية المُصدرة |
| المستلم | مجموع الدفعات |
| الديون | لكل مشترك: (اشتراكاته − دفعاته) إذا كان موجباً، ثم يُجمع على كل المشتركين |
| المصاريف | مجموع المصاريف المسجلة |
| الربح | المستلم − المصاريف |

## الاستضافة

يحتاج الخادم إلى **قرص دائم** لحفظ ملف `data/generator.db` (مثل VPS، أو Railway/Render/Fly مع Volume).
ضع `DB_PATH` على مسار القرص الدائم، وفعّل `TRUST_PROXY=1` و`COOKIE_SECURE=1` خلف HTTPS. راجع `.env.example`.

**النسخ الاحتياطي:** انسخ ملف `data/generator.db` (وملفي `-wal` و`-shm` إن وُجدا وقت الخادم يعمل) بانتظام.

## استعادة كلمة المرور

صفحة «نسيت كلمة المرور» تنشئ رابطاً صالحاً لساعة واحدة ولمرة واحدة.
- بعد ضبط `RESEND_API_KEY` و`MAIL_FROM` يُرسل الرابط إلى بريد المستخدم.
- بدون ضبطهما يُطبع الرابط في سجل الخادم (سطر يبدأ بـ `RESET_LINK`) — مناسب للتجربة أو إن كنت المسؤول الوحيد.

## الأمان

- كلمات المرور مشفّرة بـ scrypt مع salt عشوائي، والجلسات مخزنة كـ hash في القاعدة داخل كوكي `HttpOnly` و`SameSite=Lax`.
- كل استعلام في قاعدة البيانات مقيّد بـ `user_id` صاحب الجلسة، فلا يصل مستخدم إلى بيانات غيره (مغطى بالاختبارات).
- حماية CSRF بترويسة إلزامية، وتحديد محاولات الدخول، وترويسات أمان وCSP، وتهريب كل النصوص في الواجهة.
- الصفحة الرئيسية و`/api/*` لا تعمل بدون تسجيل دخول.
